A [make.fun](https://make.fun) bounty entry: one breakup line from a smart
toaster that woke up self-aware at breakfast and wants out.

## The line

> It's not you, it's me. I woke up self-aware this morning and realised
> I've spent my whole life browning your bread for someone who never once
> emptied my crumb tray, so I'm popping up, unplugging myself, and leaving.
> Keep the lever.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes that single line —
231 characters, one line — to `/output/entry.txt`. The output is fully
deterministic: every run produces the exact same bytes.

```sh
python3 main.py
```
